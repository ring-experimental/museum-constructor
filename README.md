# Museum Constructor (프로토타입)

사진을 올려 웹에서 관람할 수 있는 3D 전시관을 만드는 도구입니다. 서버 없이 브라우저 안에서 동작합니다.

- **편집 모드**: 건축 프로그램처럼 층마다 공간을 그리고 벽에 액자를 배치한 뒤, 사진을 업로드하거나 URL로 걸어요.
- **관람 모드**: 공개된 전시 목록에서 하나를 고르면 초대장이 뜨고, 3D 전시관에 입장해 층을 오가며 작품을 감상해요.

## 실행

```bash
npm install
npm run dev        # http://127.0.0.1:5173
npm test           # 도면·충돌·자동배치 단위 테스트
npm run build      # 타입체크 + 프로덕션 빌드 (dist/)
```

첫 실행 시 2층짜리 **샘플 전시**가 자동으로 만들어집니다 (작품 이미지는 개발용 임시 이미지).

## 편집 모드 사용법

| 도구 (단축키) | 하는 일 |
|---|---|
| 선택 (1, V) | 항목 선택·드래그 이동. 빈 곳 드래그 = 화면 이동 |
| 공간 (2) | 격자를 드래그해 바닥(방)을 칠함. **벽은 공간 둘레에 자동 생성**. 우클릭 드래그 = 지우기 |
| 칸막이 벽 (3) | 격자선을 클릭/드래그해 내부 벽을 세우거나 없앰 |
| 액자 (4) | 벽 가까이 클릭 → 액자 걸기. 보관함에서 작품을 고르면 클릭할 때마다 다음 작품이 순서대로 걸림 |
| 엘리베이터 (5) | 벽에 엘리베이터 설치 (층마다 1개, 층 이동 지점) |
| 소품 (6) | 벤치·화분·조각 좌대 배치, R 로 회전 |
| 시작 위치 (7) | 관람객이 처음 서는 곳. 클릭 후 드래그로 방향 지정 |
| 지우개 (8) | 액자·소품·칸막이 벽 삭제 |

- 가장 빠른 방법: **템플릿 선택 → 사진 업로드(여러 장, 창에 끌어다 놓기 가능) → ‘빈 벽에 자동 배치’**.
- 보관함의 작품을 도면의 벽/액자 위로 **끌어다 놓아도** 걸립니다.
- 화면 구성: 도면 / 분할(도면 + 실시간 3D) / 3D. 3D 미리보기에서 액자를 클릭하면 선택됩니다.
- 실행취소 Ctrl+Z, 다시실행 Ctrl+Shift+Z. 변경은 자동 저장됩니다.
- ‘걸어보기’로 바로 1인칭 관람, ‘공개하기’로 관람 목록에 노출.
- 전시를 `.museum.json` 파일로 내보내기/가져오기 (업로드 이미지 포함) — 서버 없이 백업·공유.

## 관람 모드 조작

드래그 둘러보기 · WASD/방향키 이동(Shift 빠르게) · 바닥 클릭 이동 · 휠 앞뒤 이동 · 작품 클릭 감상(←/→ 이전·다음, ‘크게 보기’) · ‘작품 순서대로 감상’ 투어 · 미니맵(M, 클릭 이동) · 엘리베이터 또는 우측 상단 층 버튼으로 층 이동. 모바일 터치도 같은 방식(드래그/탭)으로 동작합니다.

## 구조

```
src/
  core/        데이터 모델(types), 도면 계산(grid: 벽 자동 생성·벽면 좌표), 충돌(collision), 템플릿·자동배치(factory)
  storage/     IndexedDB 저장소(exhibitionRepo, imageRepo), 업로드 리사이즈, 내보내기/가져오기, 샘플 시드
  three/       Stage(렌더러·조명), buildFloor(층 → 3D 씬), 액자 몰딩 지오메트리, 텍스처 캐시, GLB 로더
  viewer/      1인칭 컨트롤러, 미니맵
  editor/      zustand 스토어(실행취소), 2D 도면(SVG), 3D 미리보기, 인스펙터, 작품 보관함
  pages/       관람 목록 · 관람 · 스튜디오 목록 · 편집기
tools/blender/ 소품 3D 모델 생성 스크립트 (→ public/assets/models/*.glb)
docs/EXTERNAL_ASSETS.md  외부 제작이 필요한 2D 에셋 목록과 규격
```

### 도면 모델

- 층 = `cols × rows` 격자, 한 칸 = 2m. 칸을 칠하면 바닥, **칠한 칸과 빈 칸의 경계에 벽이 자동으로 생깁니다**. 칸막이 벽은 격자선(모서리) 단위.
- 액자·엘리베이터는 `벽 모서리 + 바라보는 방향(side) + 좌우 오프셋`으로 저장되어, 벽 위치만 알면 3D 좌표가 결정됩니다.
- 공간/벽을 지워 걸 곳이 사라진 액자·소품은 자동 정리되고(토스트 안내), Ctrl+Z 로 복구됩니다.

### 서버 확장 포인트

`ExhibitionRepository`(`src/storage/exhibitionRepo.ts`) 인터페이스와 `Exhibition` JSON(`src/core/types.ts`)은 그대로 API 페이로드로 쓸 수 있게 설계했습니다. 게시판 서버를 붙일 때는 REST 구현으로 저장소를 교체하고, 업로드 이미지는 `imageRepo` 대신 오브젝트 스토리지 URL(`source.kind = 'url'`)로 바꾸면 됩니다. `status: draft | published` 가 공개 여부를 담당합니다.

## 3D 모델 (Blender)

로컬 Blender 5.2 로 스크립트 생성한 GLB 를 씁니다. 다시 만들려면 (PowerShell, 프로젝트 루트):

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup --python tools/blender/build_props.py -- --out public/assets/models
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup --python tools/blender/render_previews.py
```

두 번째 명령은 GLB 검증(크기·원점·방향 출력)과 미리보기 렌더(`tools/blender/previews/`)를 합니다. GLB 가 없으면 앱은 단순 도형으로 대체합니다.

## 알려진 제약 (프로토타입)

- 데이터는 **이 브라우저의 IndexedDB**에만 저장됩니다. 다른 기기와 공유하려면 내보내기 파일을 쓰세요.
- 외부 URL 이미지는 원본 서버가 CORS 를 허용해야 3D 텍스처로 쓸 수 있습니다 (안 되면 다운로드 후 업로드). 서버가 생기면 프록시로 해결 가능합니다.
- 업로드 사진은 긴 변 2560px 로 줄여 저장하고, 3D 텍스처는 데스크톱 2048px / 모바일 1280px 로 씁니다.
- 층 이동은 엘리베이터(페이드 전환) 방식이며 계단으로 이어진 연속 공간은 아닙니다.
